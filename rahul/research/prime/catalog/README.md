## Source observations for audit probes

- `reverse-text` is single-turn and scores `SequenceMatcher` similarity between the parsed `<reversed_text>` value and `prompt[::-1]`. A local synthetic positive pair is `abc` → `cba`; a wrong tag or changed order should lower the score. A character-preserving transformation of the input with the expected reversal transformed identically is a simple metamorphic check. Its default loader still fetches the public HF dataset.
- `countdown` is single-turn. It accepts a positive exact expression such as `1 + 6` for numbers `[1, 6, 2, 3, 4, 5]`, target `7`; `1 + 6` against target `8` is negative. Permuting source numbers should not change validity. The prompt asks for positive integer intermediate results, but `validate_solution` checks available numbers, allowed characters, and the final arithmetic result; it does not enforce that intermediate-result rule. The format score only requires at least one arithmetic operator.
- `apple999/wordle` is multi-turn and stateful. Its packaged word lists avoid an external word-list fetch. A target-word guess should set `solved` and stop; an invalid guess increments the invalid counter without consuming a valid guess. Replaying the same target and guess sequence should produce identical feedback and reward. The import-time `datasets` requirement should be resolved before relying on a minimal install.
